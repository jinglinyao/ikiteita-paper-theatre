| M1 黑纸手 | 重做。手指朝下、拇指和食指对捏；手臂加长到 4.2 米，从侧幕外平伸进来，不再断在半空；落点是指尖刚碰到纸角；纸角就在捏的位置翘起；纸被捏住以后直接挂在手上（位置 = 手的位置），提起后垂着被带走；灰纸也是垂着带回来、放平。手在小节 39 的切点前退完。 |

| M4 鸟停着像一个 V、落在手腕 | 停落点改到掌心中央；停着时侧对镜头，翅膀半收（24°）。台唇上同样处理。 |
