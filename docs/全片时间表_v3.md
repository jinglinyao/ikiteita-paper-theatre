# 全片时间表 v3（舞台）

2026-11-13。取代 v2（按第 ②③ 步的两份独立审核返修，逐条处理见 `docs/返修记录_第二三步.md`）。舞台上的布景、灯、窗、灯泡、天幕、纸幕、道具和 lin 的在场与否，全部由影片时间决定。实现在 `unity/Assets/Stage/FilmClock.cs`：给一个时间，它就把舞台摆成那一刻的样子。机位不归它管。

时间按歌的小节和拍写（每小节四拍；小节 26 = 0:55.2，小节 57 = 2:02.3，小节 86 = 3:04.5）。纸做的东西每秒动 12 格，光是连续变的。

v2 相对 v1 的改动来自独立审核（11 条必须改）：状态变化都落在切点上并在四分之一秒内完成；任何东西不在画面里凭空出现或消失；黄昏段跟镜头对齐；第一段副歌的窗亮到副歌结束。

## 6. lin 什么时候在台上

小节 26–29、49–52、58 到 60 第三拍、68 到 3:05.6（电视熄灭）。前三段站在 x = −0.5；最后一段站在 x = 0.05，正对纸人那一排中间的空档，六个都不被她挡住。上下场各用 0.15 秒把她的三盏灯带起和收掉（结尾 0.4 秒）。她头发材质自带的一点发光也跟着她的灯走，全黑时不会剩下一串亮点。她的姿势另有时间线（`StagePerformer.POSE_TRACK`）。
