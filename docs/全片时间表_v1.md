# 全片时间表 v1（舞台）

2026-11-14。这是全片制作的第一步：让舞台上的布景、灯、窗、灯泡、天幕、纸幕和 lin 的在场与否，全部由影片时间决定。实现在 `unity/Assets/Stage/FilmClock.cs`；给一个时间，它就把舞台摆成那一刻的样子。机位不归它管。这一步还没有道具（红纸、纸鸟、纸带、纸雨、纸屑雪）、没有动物头纸人，lin 只有一个姿势。

时间按歌的小节和拍写（每小节四拍，小节 26 = 0:55.2，小节 57 = 2:02.3，小节 86 = 3:04.5）。预览是从“电视机位”拍的，它也是房间里那台电视要放的画面。

## 2. 布景的运动

| 东西 | 什么时候 | 怎么动 |

| 另一栋楼（左）| 小节 9 | 从吊杆层降下来 |
| 远楼 | 小节 9 第三拍到小节 10 第三拍 | 降下来 |

## 4. lin 什么时候在台上

小节 26–29、49–52、58–61、69–85。其余时间她不在（追光、暖边光、后侧冷光也跟着关）。
