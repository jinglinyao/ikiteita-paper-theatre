# 《显像管的外侧》搭景计划表 v1

2026-11-13。这一轮只搭场景，不做全片、不动 lin 的表演、不渲成片。

## 0. 这一轮要解决什么

上一版样片被指出三件事（用户原话）：

> 因为视角的改变，没有建模的地方暴露出来了，没有光影的地方也暴露了，甚至整个舞台后方也暴露出来了。

这一轮的指令（用户原话）：

> 根据计划表去下载模型资源，做纸模型，每个空间都做做成封闭式的，为了保证不穿帮，直接铺满每个空间。光源不必铺满每个空间，只需要根据计划表设置光源。

我对这两句话的理解（不是用户原话）：

- “封闭式”= 每个空间六个面都有实体，从空间里任何一点往任何方向看，视线都落在建好的东西上。
- “铺满”= 六个面和中间的地面都有具体的建模内容，没有只贴一张图的大平面。
- “光源按计划表”= 只放镜头表用得到的灯；照不到的地方保留一层很暗的蓝色环境光，不是纯黑。

## 5. 怎么验收

| 检查 | 做法 | 通过标准 |
|---|---|---|
| 封闭 | 每个空间里放一组探头（3 个高度 × 3 × 3 个位置），每个探头朝上下左右前后各渲一张，背景设成洋红色 | 洋红像素为 0 |
| 铺满 | 对照第 2 节的表，一面一面查有没有做 | 每一面都有表里写的内容 |
| 光 | 同一组探头按正常灯光渲一遍，统计纯黑像素 | 没有成片的纯黑；该亮的灯在画面里看得见 |
| 镜头 | 现有六个镜头的机位再查一遍露空 | 0% |
| 质感 | 舞台世界里不出现照片贴图；房间里不出现卡纸 | 抽查材质清单 |
| 独立审查 | 把探头图和全景图交给子代理看 | 按它的意见改完 |

## 6. 先后顺序

1. 计划表交子代理审核，按意见重写。
2. 下载并导入模型。
3. A 台内：补全两栋楼，做地面、侧墙、侧幕、吊杆层、后墙。
4. B 观众厅。
5. C 房间和 D 窗外。
6. 按光源表布灯。
7. 跑探头检查，出图，交子代理审查。
8. 按审查意见调整，再跑一遍检查。

全片渲染、lin 的动作和口型、动物头纸人、电视屏幕里的画面序列、烤间接光、字幕和声音。
