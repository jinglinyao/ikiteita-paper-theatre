# 《显像管的外侧》纸剧场音乐片：文字脚本与预算（v1，待你确认）

歌曲：あいみょん《生きていたんだよな》（她曾活过啊），3 分 13 秒，实际有声部分到 3 分 08 秒。
形式：一台老式显像管电视，电视里是纸剧场；电视外是夜里的一间小房间。唱的人是 jinglin。

这一版里有四个我替你先定的假设，不同意就改：
1. jinglin 用现在的造型，不换装。
2. 另开一个新的 Unity 工程，不动正在用的 `unity_mv`。
3. 不出现人体、坠落和血迹；全片只有一处红色，是一小张红纸。
4. 底部放中日双语歌词字幕，只淡入淡出。

## 一、故事（先读这一段）

夜里，一个女孩独自在房间看电视。新闻说，两天前附近有个和她差不多大的女生从楼上跳了下来。

电视里的一切都是纸做的。街角是纸板搭的，围观的人是连成一串的纸人，一模一样，每人举着一小块发亮的白纸。警戒带一拉，纸人反而围得更密。没人看见那个女生，纸街上只有路灯下一小张红纸。

她看着那张红纸，哭了。她发现自己是隔着一层玻璃在哭，电视外面的人什么都不知道。于是她说出整首歌里最重的那句话：她活过。每说一遍，就有一扇小窗亮起来，窗里是那个女生生活过的痕迹：课桌、便当、雨伞、自行车、玄关的鞋。

第二天，纸街上来了穿黑衣的检场人，就是舞台上换布景的那种人。他们两秒钟就把红纸换成了一张干净的灰纸。纸人们还在议论，说这种事只在电视剧里见过。太阳沿着杆子滑下去，一天就这么过完了。

她回头看自己的桌子：课本、便当盒，和小窗里的一模一样。她和那个女生没什么不同。新的一天要开始的时候，她也会想消失吗？

这时布景全部撤走，只剩光秃秃的后墙和一盏工作灯。“珍惜生命、好好活着”这种话，在空台上听起来只是漂亮话。

空台中央，那张红纸自己立了起来，一折一折，折成了一只鸟。它穿过纸云往上飞，飞出了电视，落进她的房间，落在她摊开的手上。

她没有救到谁。她只是成了唯一记住那个女生的人。她把纸鸟放在自己的课本上，对着电视里那个空着的光圈喊了最后一声再见，关掉电视，拉开窗帘。天亮了。

**情绪的走向：** 冷眼旁观 → 被刺痛 → 认出“她活过” → 看着她被擦掉的无力 → 自己也摇晃 → 拒绝漂亮话 → 接住、记住 → 天亮。

**三个贯穿的东西：**
- 红纸：现场 → 被换掉 → 折成鸟 → 落在她手上 → 留在桌上。
- 小窗：第一次副歌亮 6 格，第二次 20 格，最后一次整个舞台都是亮着的窗。
- 屏幕玻璃：镜头四次穿过它（进、出、鸟飞出、关机），每次穿过都是一次段落转换。

**快慢怎么衔接：**
- 主歌是快的，但我不靠快切来表现，靠纸片机关的密度（纸人滑入、纸带拉起、白纸片逐拍闪）。
- 从快到慢的两处（06→07、16→17）都用“推到一个静止的小东西上”来减速：红纸、她的手。
- 从静到最强的一处（19→21）用机关逐级加码：空台 → 一张纸立起 → 云层降下 → 鸟冲出屏幕。

**敏感内容的处理：**
- 不表现跳、不表现现场，红纸是唯一的指代。
- 结尾不把“飞走”拍成解脱：鸟不飞向天空，而是飞回房间落在活着的人手里。
- “会想消失吗”那两句，画面给的回答是她留下来了，并且拉开了窗帘。
- 建议片尾署名里加一行心理援助提示，具体文字发布前按平台要求核实。

### 风险和备用办法
| 风险 | 可能的表现 | 备用办法 |
