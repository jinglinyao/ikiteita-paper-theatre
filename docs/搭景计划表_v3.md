## 3. 模型质量标准

### 3.1 对照 The Edge 定的七条

参考是 The Edge 制作说明里的十四张剧照。它是光线追踪渲的，我们是实时渲染，光影的柔和程度追不上；下面七条是不靠光线追踪也能对照的。

| 编号 | 它的做法 | 我们的标准 |
|---|---|---|
| 1 | 每条棱都有一条细高光 | 厚度 ≥ 10 的零件每条棱倒 3 的斜角 |
| 2 | 墙上的影子有形状（窗格、叶子）| 第 5 节每盏灯都写了它要投出的影子 |
| 3 | 哑光和亮面对比（墙、木桌、玻璃、黄铜）| 舞台上：哑光卡纸、上漆木地板、黄铜色灯座、玻璃灯泡；房间里保留原材质 |
| 4 | 灯本身在画面里 | 路灯、窗、台口灯泡、裸灯泡、台灯、电视都是看得见的灯 |
| 5 | 近景有虚的前景、主体、虚的背景三层 | 布景在深度上至少分五层：侧幕、lin 的位置、路灯、楼、远楼、天幕 |
| 6 | 每个画面有冷暖对比 | 夜街：蓝色的泛光和月光对琥珀色的窗和路灯 |
| 7 | 画面里没有既没细节又没明暗的面 | 第 7 节的“光板占比”和“零直射光占比”两项检查 |

### 3.2 按机位远近分三档

| 档 | 机位到表面的距离 | 最小几何细节 | 贴图密度 | 谁在这一档 |
|---|---|---|---|---|
| 近 | < 600 | 2 | 每米 ≥ 12,000 像素 | 滑槽边、红纸落点周围的路面、电视正面、桌面小物、裸灯泡、窗框 |
| 中 | 600…3000 | 10 | 每米 ≥ 3,400 像素 | 楼的正面、远楼、云、路灯、台口、侧幕 |
| 远 | > 3000 | 30 | 每米 ≥ 1,000 像素 | 天幕、吊杆层、后墙、显像管腔 |

贴图密度的做法：卡纸仍然用 2K 的纸张扫描图每 600 铺一次（每米 3,413），再叠一层每 60 铺一次的纸纤维细节贴图（每米约 17,000），近档靠它。木地板改成每 600 铺一次并叠同一层细节。房间里进近档的四件（电视、笔记本、闹钟、书桌）下载 4K 或 8K 的贴图。

## 5. 光和影子

只放表里的灯。位置是毫米。“真灯”是会照亮别的东西的灯，“自发光”只是自己亮。灯的总数超过每个物体 8 盏的上限，所以渲染路径改成 Forward+（改之前先确认 lin 的卡通材质在这个路径下亮度不变，变了就退回并把窗灯合并）。

## 7. 怎么验收

每一项都出数字和图。舞台按“夜街”“只剩追光”“空台”三个状态各跑一遍。

| 检查 | 做法 | 通过标准 |
|---|---|---|
| 机位清单 | 把镜头表 83 个镜头归成约 40 种机位（每种写成位置、朝向、焦距），每种再前后左右各偏 300，视角放宽 25% | 清单本身交审 |
| 露空 | 机位清单和 27 个格点探头，背景洋红，原尺寸、关抗锯齿 | 洋红像素为 0 |
| 光板占比 | 把封闭用的外壳（墙、封顶板、腔壁、夜空纸）渲成一种颜色，统计每帧里占多少 | 机位清单里每帧 < 15%，超过的逐条列出并说明 |
| 零直射光占比 | 环境光设成 0 再渲，统计非外壳面里全黑的比例 | 机位清单里每帧 < 25%（窗洞里的暗、夜空除外），超过的列出 |
| 素面 | 关掉计划里的灯，只开一盏头灯，把画面分成 32 像素的格子，格子里没有边线的算素面 | 机位清单里中档和近档的帧 < 10% |
| 朝向 | 列出所有没有厚度的面片；除了窗纸、剪影和夜空纸，不允许有 | 清单为空 |
| 锐度 | 每种材质按最近的机位算“一个屏幕像素对应几个贴图像素” | ≥ 1；小于 1 的列出 |
| 尺寸 | 把第 2.3 节和第 3.3 节的零件实测尺寸打印出来对表 | 误差 ≤ 1 |
| 影子 | 第 5 节投影的灯逐盏单开，各渲一张 | 表里写的影子在图上看得见 |
| 材质 | 全量列出舞台世界里每个材质用的贴图 | 只有纸张、卡纸、木板的扫描图和细节图 |
| 独立审查 | 上面的图和数字交给子代理 | 按它的意见改完，再跑一遍 |
